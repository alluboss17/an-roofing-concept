# RidgeCraft Roofing — AN Digital Studio Concept

A fictional UK roofing website concept designed to demonstrate AN Digital Studio's approach to service clarity, project proof and enquiry UX.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production domain

Recommended: `roofing.andigitalstudio.com`

This demo is intentionally noindexed through `app/robots.ts` and the metadata robots directive.

## Images

See `public/images/README.txt`. The site still renders if the optional JPG files are absent.

## Before using for a real client

Replace all fictional/example content with verified business details, real services, service areas, accreditations, insurance information, review sources, contact information and client-owned/licensed project photography.
